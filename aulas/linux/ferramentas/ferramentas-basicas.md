# Ferramentas básicas

Feramentas como SSH, Netcat, tmux e nano são usadas diariamente pela maioria dos profissionais da IS (até do ti). Essas ferramentas não foram criadas para pentest mas pelo menos uma delas está presente quase todas as vezes, então é bom que você aprenda a usar. Até por que ninguém quer ser o "pentester" que só mexe em GUI

## Secure Shell

A primeira ferramenta útil é o SSH, a gente vai falar dele na aula de [SSH](ssh/ssh.md)

## Netcat

O netcat é uma ferramenta bipolar que não decide um nome só, pode ser netcat, ncat ou nc, mais detalhes [aqui](nc/netcat.md)

## Tmux

O Tmux é um multiplexador de terminal. Ele serve pra adicionar funções no terminal linux padrão, como várias janelas num terminal e pular entre elas, como se fosse uma tv
aula de Tmux [aqui](tmux/tmux.md)
