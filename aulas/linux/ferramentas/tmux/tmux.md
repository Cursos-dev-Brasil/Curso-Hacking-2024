Se o tmux não estiver instalado no seu linux você pode baixar com o apt (mesmo sendo raro, ele é tipo o primeiro socorros de um kit de sobrevivência)

Depois de instalar, você pode iniciar o tmux usando o comando `tmux` (é, é só isso, ebaa)

A tecla padrão para adicionar comandos no tmux é o prefixo [CTRL + B]. Para abrir uma nova janela no tmux, basta pressiona `[CTRL + b] + c`

As janelas vão ser numeradas na parte inferior da tela, para trocar de janela você pode usar prefixo + o número da janela

O tmux é muito útil pra certas coisas, uma delas é o logging (que sempre é útil, confia em mim)
