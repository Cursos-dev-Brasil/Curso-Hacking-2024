# Protocolo SMB

Imagine que você está tentando encontrar o dinheiro escondido em uma casa. Em vez de arrombar todas as portas, você observa a casa, procura janelas abertas, ouve conversas e tenta descobrir a rotina dos moradores. Isso é o que os hackers fazem com os computadores, mas com muito mais burocracia e texto

## O que é Enumeração?

Enumerar é fazer um inventário de tudo o que tem em um computador ou rede. É como fazer uma lista de compras, mas em vez de itens, você lista informações

Exemplos de informações obtidas em enumeração

Quem usa o computador? (usuários)
Quais programas são usados? (serviços)
O que está compartilhado? (arquivos, pastas)
Quais são as fraquezas do sistema? (vulnerabilidades)
Por que a Enumeração é Importante?

Saber essas informações é como ter uma chave para abrir uma porta. Se você sabe que alguém deixou a porta dos fundos aberta, é mais fácil entrar na casa, certo? A enumeração ajuda os hackers a encontrar as portas abertas em um sistema e invadi-lo.


SMB é como um armário onde você e quem quiser guardam dados, o SMB é usado para compartilhar arquivos e impressoras. Os hackers adoram explorar esses sistemas porque podem encontrar arquivos interessantes lá dentro.

### Enum4Linux: A Ferramenta Mágica

Enum4Linux é uma ferramenta que ajuda os hackers a explorar esses sistemas. É como um detetive que procura pistas em uma cena de crime. Com essa ferramenta, os hackers podem descobrir:

Quem tem acesso usando a flag `-U`
O que está dentro usando a flag `-S`
Quais são as regras usando a flag `-P`
