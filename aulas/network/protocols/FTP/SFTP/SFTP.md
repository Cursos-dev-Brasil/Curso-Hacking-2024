# SFTP

O SFTP é uma variante do FTP. A porta padrão dessa variante é a 22, além disso ele usa a mesma porta para mensagens de controle e transferência de dados 

O motivo para isso é que o SFTP Não tá exatamente conectado ao FTP. SFTP é um protocolo seguro sobre SSH modelado da forma do FTP. No SFTP, tanto credenciais tanto dados são criptografados, e você pode usar chaves SSH para autenticar a conexão
