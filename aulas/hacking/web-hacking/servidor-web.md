# Servidor Web

O servidor web é um fornecedor, recebe pedidos http e entrega pras páginas que você procura. Servidores costumam rodar na porta 80 e 443 e conectam o usuário final com várias partes da aplicação, eles também lidam com as respostas (ele fornece mas também cobra os produtos que ele entregou)

Como são abertas ao público são alvos fáceis se forem vulneráveis, é quase como deixar seu diário aberto em cima da mesa (péssima ideia)

Existem vários tipos de vulnerabilidades que afetam aplicações web, e o [OWASP TOP 10](OWASP/) detalha isso perfeitamente
