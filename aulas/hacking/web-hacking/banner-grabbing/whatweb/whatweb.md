# What web

As vezes você pode querer roubar uns dados relacionados ao servidor, framework e aplicações usando o whatweb

`Klython@root[/~]$ whatweb 10.10.10.121`

```
http://10.10.10.121 [200 OK] Apache[2.4.41], Country[RESERVED][ZZ], Email[license@php.net], HTTPServer[Ubuntu Linux][Apache/2.4.41 (Ubuntu)], IP[10.10.10.121], Title[PHP 7.4.3 - phpinfo()]
```

O what web é útil pra você que tem preguiça de enumerar as coisas manualmente

`anotherMan@htb[/htb]$ whatweb --no-errors 10.10.10.0/2`
