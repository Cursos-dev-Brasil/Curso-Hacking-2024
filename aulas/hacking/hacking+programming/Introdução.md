# Hacking

Todo aspirante a hacker precisa aprender a usar uma linguagem de programação para descobrir e explorar vulnerabilidades em um sistema. Como eu disse na aula de [Introdução ao hacking](/aulas/hacking/introdução/comecando.md#programação), não tem nada errado em usar ferramentas prontas e feitas para o hacking, mas além de você estar fadado a ser um Script Kiddle pro resto da vida, você vai estar limitado a fazer exatamente o que a ferramenta tem disponível, sem opção de personalizar sua ferramenta. Por isso, criar o próprio script pode ser interessante

Usar ferramentas antigas ou muito famosas pode acabar te dando uma dor de cabeça lascada, em primeiro lugar por que essas ferramentas já tão manjadas e os anti-vírus (se atualizado) já tem conhecimento delas, então além do ataque falhar, você provavelmente seria descoberto bem rápido

Aprender uma linguagem (e consequentemente criar suas ferramentas) aumenta a chance de sucesso do ataque e diminui a chance de ser detectado por um Intrusion Detection system (IDS), um anti-virus ou ferramentas usadas pela policia

## Python 

### O que é python?

Python é uma linguagem de código aberto. O que significa que é instalado de graça e o código fonte pode ser visto e alterado por qualquer um. Essa linguagem é dos anos 80 mas sobreviveu ao tempo e hoje é usada pra apps, web apps, softwares, gui, jogos e o mais importante, criação de exploits e automação de ferramentas de hacking

Se você sabe outra linguagem de programação, aprender python vai ser muito fácil. Grande parte dos comandos (se não todos) usa o inglês padrão. Se você sabe o básico de inglês vai ser muito fácil aprender python. 

Código python é menor e mais limpo do que outras linguagens de auto nível, como por exemplo o java

Vamos usar um hello world como exemplo

```java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

Python:

`print("Hello, world!")`

Provavelmente você já tá amando o python e odiando o java, mas relaxa, você não é o primeiro e muito menos o último

Se é sua primeira vez, você vai achar python bem fácil de aprender. O python roda em android, windows, Linux e macOS. Pulando pro hacking, o python pode ter muito divertido, principalmente quando você descobre que ele pode ser usado pra manipular quase o que você quiser, desde laptops, desktops, smartphones até microcontroladores em brinquedos, controles remotos, aparelhos, ou qualquer, literalmente qualquer dispositivo que tenha um computador
