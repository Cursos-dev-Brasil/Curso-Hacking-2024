# Começando com python

A versão mais nova do python é a 3.12.6. Mas, o python 2 pode ser mais compátivel com o seu dispositivo do que o python 3, mas o python 3 é considerado o futuro da linguagem e tem ferramentas e bibliotecas inteligentes

## Interagindo com python

Assumindo que você baixou o python pelo [python.org](https://python.org) e tem uma CLI (Command Line interface) vamos começar com comandos padrão pra entender a sintaxe da linguagem

O primeiro comando que você vai usar é o inicializador do interpretador python

```py
$ python
Python 3.11.8 (tags/v3.11.8:db85d51, Feb  6 2024, 22:03:32) [MSC v.1937 64 bit (AMD64)] on win32
Type "help", "copyright", "credits" or "license" for more information.
>>>
```
os quatro ">" indicam que o interpretador está rodando naturalmente

**OBS: essa forma não é a ideia para escrever código em python mas é a mais simples, para escrever códigos grandes você precisa usar um IDE para maior organização e pra escrever códigos maiores**


```py
>>> print("hello, world!")
hello, world!
>>>
```

Se você errar o comando a saída vai ser mais ou menos assim

```py
>>> print "hello, world)
  File "<stdin>", line 1
    print "hello, world)
          ^
SyntaxError: unterminated string literal (detected at line 1)
>>>
```

tem três formas de deixar o interpretador:

`>>> exit()`

`>>> quit()`

`CTRL + Z + enter`
